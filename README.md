# Data Structures Chat Engine

A terminal-based one-to-one chat application built to demonstrate how core data structures support real product features.

## Why it matters

Messaging products depend on efficient storage, lookup, ordering, search, and undo operations. This project makes those foundations visible without hiding them behind a large framework.

## What it demonstrates

- Users stored and tracked with arrays and sets
- Conversations routed through a custom hash map
- Messages stored in a linked list
- Undo powered by a stack
- Chat history and keyword search

## Technology

Python and custom data-structure implementations.

## Run

```bash
python main.py
```

No external services are required.
